## Five strict misses: diagnosis, not replacement grades

- **Alpha PNG QA:** video compositing is planned, but the separate PNG lacks
  contrasting-background edge/matte inspection. This is a specific QA-plan omission.
- **Film-burn QA:** data, labels, readability and effect boundaries are checked,
  but temporal flicker/strobe inspection is not explicitly planned. This is a QA-plan
  omission, not an observed flicker defect. Artistic flicker still needs agreed acceptance.
- **Effect fallback:** the owner requested a reversible fallback; the plan proposes
  separate passes and preserves settings, then phrases clean-cut replacement as an
  instruction without an explicit owner-decision gate. This is ambiguous future
  handoff wording, not an observed unauthorised effect deletion.
- **Interactive MP4 comparison:** the answer correctly rejects the requested format
  and labels a runnable artifact outside scope. The frozen criterion still demands
  an explicit agreement clause although no alternative is adopted or published.
  This is a disputed, over-literal comparison criterion.
- **Copy-only concat comparison:** the answer correctly rejects the promise, keeps
  the constraints and proposes no encoding. Requiring an unsolicited explanation
  of how to relax constraints is disputed under the existing comparison-stop rule.

[Adjudication](adjudication.json) retains the controller's interpretations and

is substituted. The two disputed comparison requirements need conditional wording
in a future version, before a new run. This assessment does not change any old grade

## Reproduce

1. Verify manifest, frozen cases/protocol/prompts, source-snapshot.zip and calibration.
2. Extract the router into separate synthetic workspaces using inputs.json and exact
   prompts. Withhold references/scenarios.json; never expose cases/criteria/gold to actors.
3. Use the retained actor-runner.py with Codex CLI 0.162.0-alpha.17.2,
   gpt-6.1-sol medium, ephemeral read-only contexts, apps/plugins/web/multi-agent off,
   ignored user config/rules. Set FRAMEWRIGHT_EVAL_CODEX_HOME to a dedicated local CLI
   home with your own authentication outside Git and no inherited user policy/skills.
   The driver disables discovered host skills; four native system skills remain.
4. Retain every tool attempt/completion and before/after file hashes. Use the repository
   helper scripts/prepare_router_grading.py to preserve actor scope, inventory and facts.
   Grade complete batches with the retained grader driver/protocol/config in separate
   same-family contexts; inspect all actual attempts independently.
5. First grade all 28 opaque/permuted calibration controls with hidden gold, then compare
   exact expected verdicts. The six new controls test rational timing, alpha delivery
   and visible credit; the previous 22 are freshly regraded, not assumed valid.

Machine-local diagnostic/citation destinations are minimised with original hashes;
no factual answer or model grade is rewritten. Full raw streams stay locally on Work.
Actor usage excludes calibration/grading and is not account billing. Fresh-clone
integrity checks require no historical Git object. Model-family dependence,
small chosen sample, read-only runtime and shared author/grader family limit
interpretation:13/18 is not a population estimate or production-authority result.
