# Scene, reuse and local-kit increment

2026-10-18. Owner selected three additions: connect script/capture/edit planning,

implementation. The prior schema-2 project/journal remains the foundation.

## Delivered behavior

- `compose` binds a strict small composition specification to the same saved
  project: catalogue, source/claim references, scene points, visual intentions,
  narration, missing work, cuts and delivery mappings. Existing projects without
  this extension remain readable. Replacement is explicit and historical.
- Catalogue records origin, file revision, role, rights basis/uses, attribution,
  restrictions and parent lineage. Unresolved parent rights, changed bytes and
  rejected/pending/stale source checks cannot be hidden by a derived item.
- Each cut has its own canvas, ordered source ranges, framing, speech and related
  task IDs. A shared capture can supply landscape and portrait versions without
  treating their edit decisions or final files as interchangeable.
- Changed cut footprints create an administrative pending video-conformance
  receipt. This does not run a decoder, reject the media or claim failed rendering.
  Unchanged source approvals and earlier QA receipts remain in history.
- `board`/`resume` expose the plan and remaining work. `bundle` copies only mapped
  unchanged finals, verifies copied hashes and text readability, and writes
  manifest/CHECKS reports. Incomplete export requires explicit `--draft`; no output
  is overwritten and the completion manifest is installed last. No task completes
  or publication becomes authorised merely by collecting files.
