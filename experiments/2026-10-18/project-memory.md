## Implemented scope

The existing project CLI now supports schema-2 goals/context, explicit tasks and
waits, declared artifacts and an append-only observation journal. Technical QA,
listening, creative acceptance, decisions, publication and provider outcomes are
separate. Observations pin target and declared source revisions, actor, manual
provenance, known observation time and recording time. Rejections remain evidence;
changed bytes or source pins make receipts stale without erasing history. A linked
check cannot be completed over a current unresolved observation. Positive receipts
do not complete tasks, authorise execution or certify facts automatically.

Old schema-1 checkpoints remain readable without writes; explicit migration saves
original bytes before atomic replacement. Manual projects support an existing
game/virtual set without inventing a tool-qualified router plan. Existing frozen
brief/packet, file invalidation, atomic writes and exclusive locking are reused.
The journal checksum detects accidental drift, not hostile tampering. Dependencies
are declared by the operator; nested media references are not discovered automatically.
