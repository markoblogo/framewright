# One object, one clear handoff

Status: authored structural example, not an executed production or qualified template.
Purpose: show how a motion specification links existing sources rather than duplicating
project state. Do not treat the sample timings or geometry as a preset for every film.

## Intent

Let the viewer follow one object from an initial location to a supported destination.
The movement should explain the transfer, not merely decorate its title. It is an
original illustration; it does not claim real model inference or hardware operation.

## Existing sources

For a real production, link its selected project journal, brand profile/design document,
editable scene, input/rights record and timing file here. This example provides none
of those production assets; missing material remains a prerequisite, not a placeholder
that may silently appear as a finished deliverable.

## Action and time

- Establish the object and destination; let the viewer identify both before the move.
- Approach, make visible contact, carry, settle and release. Object/hand positions share
  the same state while attached; the destination supports the complete resting footprint.
- Hold the meaningful result. Use the chosen source/timing when adding sound; do not
  invent a fixed one-frame sound delay or a beat for every movement.
- Keep object identity at a continuous scene handoff; an intentional reset/cut is labelled.

The actual timeline and delivery duration are selected for the new brief. This list
specifies relationships rather than a fixed sequence of equally long slides.

## Keep and replace

Keep the selected action logic, object identity, contact and support constraints.
Replace approved copy, material, palette and voice through the existing input contract.
Longer copy needs a new reading/timing decision; missing optional audio may be silent.
Inspect each requested aspect independently; do not deform or blindly crop the source.

## Review and evidence

Check the actual grip, carry, release and annotation regions in the encoded result.
Compare corrections at matching times with nearby context. Record exact files and
technical versus creative/listening decisions in the existing journal. Validate any
reuse with materially different content, not only a new title; run and report that trial
before calling it reproduced. Current example execution, viewing, listening and owner
acceptance: not performed.
