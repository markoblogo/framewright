# Source-photo explainer example

Own source only; vendor bundles, photographs, audio, models and caches are not
included. The original production is recorded in
[the experiment](../../docs/experiments/exin-agent-explainer.md).

For a new authorised case, copy this example to a private folder and provide
`audio/voice-manifest.json`, `timeline/camera.js`, local source images and licensed
local PixiJS/GSAP assets. `build-film.py` expects the explicit source/timing contract
from that production; it does not fetch or authenticate a news report.

The camera script is deliberately case-specific: crop coordinates refer to the
supplied1280px photographs. Replace sources and camera definitions together.
It is not a generic detector, medical-analysis tool or automatic factual validator.
Use a new output revision, retain source hashes, check seeking and review every
crop. Photo movement is not documentary live footage or simulated surgery.
