## Title

How Color Changes a Scene | One Forest, Three Feelings

Alternative: The Same Forest Feels Different in Every Color

## Description — copy this block

One forest. One traveler. Three very different feelings.

This 42-second animated experiment explores how color grading, lighting and sound can turn the same setting into loneliness, shelter or unease. Cool blue gives way to warm amber, then a restrained red warning changes the mood again. Watch the lantern — and listen to how the same piano theme changes with the image.

The environment comes from my existing Loup Garou world in World Labs Marble. The character and its animation were made separately, then composited over a fixed view of the forest using the Framewright production workflow. This is a small 2.5D visual study, with a deliberately simple character, rather than a full 3D character integration.

Tools: World Labs Marble, Framewright, Three.js, Canvas and FFmpeg.
World Labs Marble: https://marble.worldlabs.ai/
