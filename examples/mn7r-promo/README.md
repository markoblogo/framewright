# Repeat the method with your own product

Asset-dependent route from the [MN7R production record](../../docs/experiments/mn7r-promo.md).
This is an observed procedure, not a standalone runnable demo or independent repeat.
Private interface images, owner voice/reference, models and client data are omitted.

1. Verify product facts and filming authority. Separate private originals from a
   sanitised render folder. Capture only authorised views; restore temporary view
   settings. Check masks at source resolution before composing.
2. Lock Motion Canvas core/2d/vite-plugin/ui3.17.2, Vite5.4.21 and TypeScript5.9.3
   in an isolated project. Use native `Renderer`/`ImageExporter`, a measured scene
   timeline and retained audio stems. Dependency/API changes require a fresh probe.
3. Start with a short owner-authorised voice sample and obtain listening approval.
   Our local Qwen Base MLX model/revision is in the case receipt. Do not substitute
   a stranger's voice, upload the reference or infer permission from this example.
4. Render a short sample, then the chosen film. Keep a separate portrait composition.
   Encode JPEG sequences with FFmpeg at their native frame rate to H264/yuv420p,
   BT.709 and AAC; keep voice-only and music mixes separate.
5. For a correction, save the defect, time range, change and protected elements.
   Native `Renderer` settings accept a selected `range` in seconds. Render to a new
   directory; inspect actual numbered frame bounds, merge only that range and compare
   hashes outside it. Re-encode final output and decode it in full. Check encoded
   picture, levels, privacy, subtitle bounds and cover readability; request owner review.

Framewright adds the existing project journal, pinned materials and separate check
receipts to these steps. An ordinary folder plus the same table/settings/checklist
is the alternative. Neither installs a provider, buys export access or publishes.
Exact local native source/lockfiles remain with the private project; no claim that
this text alone recreates the omitted product assets or the accepted voice.
