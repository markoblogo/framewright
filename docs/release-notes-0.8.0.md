# Framewright0.8.0 — Coherent character production (REL-C)

Experimental prerelease. A checked process for creating a coherent character film,
operated by an AI agent and a human, with retained sources, decisions and limitations.
Framewright remains a methods/skills library, not an autonomous hosted video studio.

## What changes

- **Carry characters through a complete story.** No Further Claims demonstrates
  approved character/environment references, linked chase shots, short authorised
  generation, cause-and-effect edits, local repairs, consistent manga lettering,
  score/effects and separate YouTube16:9/TikTok9:16 layouts.
- **Continue from the selected result.** A no-history reader recovered exact finals,
  protected decisions, retained dependencies and next authority boundary after
  cleanup. Targeted corrections preserve unaffected picture/sound where claimed.
- **Reuse lessons rather than restart experiments.** Four training cases cover
  science/PDF/ASCII explanation, animated poster collage, persistent liquid-photo
  imagery and a practical airport route. The catalogue retains rejected/unexecuted
  options, social-media packaging and the external-storage sanitation contract.
- **Keep current instructions current.** Closed recovery/PR53 statuses are reconciled;
  stale Hudson character/chase and completed portrait-pilot suggestions corrected.
  After this release the next plan is discussed with the owner, not started automatically.

## Compatibility and limits

No mandatory migration, renderer logic change, new runtime dependency or model call.
Existing CLI behavior is unchanged. This is a versioned production-method increment.
The film's workflow uses explicit manual local recipes; whole-film admitted execution,
paid-provider enforcement, stable rigs and general identity/contact quality are unproven.

Generation can drift. Crops/trims are bounded editorial repairs; they can conceal
unwanted source action, not repair its underlying motion. Bubble fit/timing still
need human review. Portrait context/detail panels repeat the same instant; generated
source is720p, portrait working720x1280 resampled1.5x to1080x1920. Family uses still/
speaker framing, not full character animation. No new independent full listening,
complete rebuild, phone-readability, audience-growth or labour-savings claim.

Music permission is owner-reported received; the grant document was not inspected.
Tools/models/media retain separate terms; Gallery Lava stock ShareAlike decision
remains open. SSI partner/autonomous-cycle and later Instagram work are not completed
by this release. Internal cold resume is not external-operator REL-D reproduction.
