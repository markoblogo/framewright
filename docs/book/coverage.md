## Как выбрать следующий полезный опыт

Сначала согласовать нужный автору ролик. Выбрать один подходящий пробел и испытать
самый маленький фрагмент, который его проверяет. Сохранить отрицательный результат
тоже: он может улучшить объяснение, ограничить обещание продукта или оставить тему
для следующего издания. Если инструмента/бюджета нет, глава использует уже проверенный
узкий пример; книга не обязана становиться каталогом всех кандидатов.

После работы обновить исходный кейс, запись в [индексе](index.json), соответствующий
разбор и эту строку. Доказательство выполнения → проверка технической части →
просмотр/прослушивание → авторское принятие → публикация → метрики фиксируются раздельно.
Для завершения главы дополнительно проверить права и понятность изложения.
