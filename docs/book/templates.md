# Общие формы для производства и книги

Формы работают с Framewright и без него. Пустое поле означает «ещё неизвестно»;
заполненная форма не означает выполненную проверку. Медиа и частные данные остаются
в рабочем проекте, а не в Git или рукописи.

## Карточка разобранной работы

```text
ID / дата / связанные главы:
Задача зрителя и автора / ограничения / критерий готовности:
Исходники: откуда, версии, доступность, права:
Реальный процесс: шаг → решение → наблюдаемый результат:
Ошибка: где и как обнаружили:
Правка: что меняем / что сохраняем / версии до и после:
Проверка: техническая / просмотр / прослушивание / принятие:
Результат: точный файл, параметры, ссылка с происхождением:
С Framewright: использованные функции и их фактическая роль:
Без Framewright: шаги, инструменты, эквивалентные записи:
Статус каждого пути: выполнен / только описан / заблокирован:
Упражнение и способ проверить повторение:
Что не доказано / что не работает / затраты и неизвестные:
Источники для текста / отдельные права на иллюстрации:
Чего не хватает: ID пробела / следующий подходящий продакшен:
```

## Папка и реестр без Framewright

```text
my-film/
  brief.md
  sources/               # неизменяемые оригиналы, в пределах разрешённых прав
  source-register.csv    # ID, имя файла, версия/хеш, происхождение, права
  working/               # сцена, монтажный проект, маски и производные
  shots.csv              # ID, время, камера, действие, источник, звук
  audio/                 # речь, музыка, эффекты отдельно
  revisions/             # именованные запросы и версии
  review/                # короткие сравнения и замечания
  decisions.md           # кто/когда/что принял, отклонил или отложил
  delivery/              # выбранная версия и нужный каналу комплект
```

С Framewright эти же сущности регистрируются в существующем проекте/журнале;
`project.py brief` помогает продолжить работу, а файлы остаются у выбранных
инструментов. Это два способа организовать записи, а не два разных стандарта качества.

## Карточка сцены и правки

```text
Сцена / диапазон кадров или секунд / версия:
Задача кадра / источник изображения / защищённые детали:
Камера: положение, цель, оптика, начало/конец движения:
Действие: объект, версия, клип, событие, перемещение:
Свет / материалы / звук / единая временная точка:
Дефект / желаемая правка / что требуется сохранить:
Предпросмотр с контекстом / фактические наблюдения:
```

С Framewright: [сцены и паспорта](../../skills/video-production-router/references/shots-and-passports.md),
[правки и сравнение](../../skills/video-production-router/references/revisions.md).
Без него: сохранённая сцена/монтаж, маркеры и таблица; исправленный участок
экспортируется заново под другим именем. Обе реализации требуют просмотра результата.

## Протокол самостоятельного повторения

```text
Какую инструкцию и её версию дали оператору:
Какие исходники/права/программы доступны:
Маршрут: с Framewright / без Framewright:
Какие шаги выполнил / где понадобилось пояснение:
Полученный файл / проверки / ограничения:
Время и расходы: измеренные / неизвестные:
Итог: выполнимо / частично / не получилось:
Что изменить в инструкции и продукте:
```

Это будущая проверка понятности, а не притворный результат эксперимента. Пока её
не провели, карточка остаётся `written_not_reproduced`. Сравниваем соблюдение задачи,
целостность материала и возможность внести правку. Не обещаем одинаковое время,
пиксели или качество разных движков. Не отправляем задания другим людям без
разрешения автора.

## Источники и иллюстрации

Для каждого изображения/цитаты: происхождение, предполагаемое использование,
право воспроизведения, атрибуция и место хранения разрешения. Ссылка на опубликованный
ролик годится как указатель; она не заменяет права на стоп-кадр в коммерческой книге.
Можно заменить неразрешённую иллюстрацию своим нейтральным учебным материалом.
