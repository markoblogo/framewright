Existing workflows are optional; no data migration is required for unchanged
projects. Newly bound saved-shot work requires explicit route selection/admission;
older unbound recipes are not implicitly admitted. Private media, scene binaries,
models, credentials and downloaded upstream code stay outside the repository.

creative approval and publishing authorization remain separate.
