# Narration selection and reserve voices

Owner decision,10November2026: prefer natural, expressive narration when an eligible route is available within the authorised resources. **Supertonic stock narration is now a reserve**, not the default. The owner accepted the picture of the YouTube experiment-results film but rejected its English Supertonic-3M1 narration as too robotic and authorised replacement plus packaging.

Preserve earlier accepted takes and their scoped technical/owner evidence. This decision does not invalidate previously published films, remove the local runtime, or change SSI operations. A technical speech integration still does not establish voice fit. Do not silently fall back to the reserve after a quality rejection; disclose the limitation and resolve the actual production.

For Ukrainian, the [Fola baseline](ukrainian-voice-baseline.md) remains. For this English film, a new Knox take was generated through the normal Chrome Google AI Studio speech UI, observed model gemini-3.8-flash-tts, with warm conversational direction. No API key, purchase or billing option was selected. The owner saved the WAV after automated data-audio export was blocked; no extraction workaround was used. The owner explicitly accepted the final replacement audio on10November. Both Dependabot/APM full films with Knox were also accepted with sound. These are scoped production decisions; Knox is not a globally owner-approved English default. The original picture approval, later sound acceptance and publication URLs remain distinct evidence.

Keep voice, direction, script, original recording/hash, paragraph cut map and final audio/picture checks. Preserve the natural timing instead of using aggressive speed changes to force a take into a locked film. Public-use rights and paid-resource authority remain separate from a voice-quality preference.


The current catalogue sets Supertonic stock `default_narration_eligible=false`.
Default discovery and complete-chain search must not silently select it.
`--tool supertonic3` inspects the retained scope; `--voice supertonic3` deliberately
requests it in a proposed chain. `--include-fallbacks` broadens discovery only.
The updated search tests cover both the blocked default and explicit reserve route;
conditional model/asset rights and fresh listening are still required. This policy
does not install a cloud voice, change SSI configuration or promise free quota.

The full offline run also exposed four stale planner/intake expectations. Updated
planner tests require a blocked default when no eligible voice exists and an
explicit reserve request for the LCD example; regenerated producer/comparison
examples preserve `UNRESOLVED` narration and route gaps. Standalone package smoke
checks request the retained reserve explicitly. No automatic substitute,
new cloud integration or runtime planner change was added.
