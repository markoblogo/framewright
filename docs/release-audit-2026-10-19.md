## Scope and useful changes

Framewright remains an agent-operated methods/skills library approaching a
personal production studio. Schema-2 checkpoints now connect goals, tasks,
explicit waits, file revisions, scoped evidence/decisions, scenes, narration,
materials, independent cuts and local publication kits. Existing files stay
usable via explicit backed-up schema-1 migration. No autonomous renderer or
uploader is claimed. Games are both content and virtual sets for other subjects;
reviews are a supported planning/capture workflow, qualified per recorded case.

17 planner profiles,48 discovery IDs,10 methods and23 recorded exports are
separate inventory units. They do not mean48 fully tested tools. Current-source
model routing remains unevaluated; historical frozen scores are unchanged.
