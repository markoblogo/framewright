## Four documented workflows, not four established capabilities

| Mode | Intended use | First useful controlled comparison |
|---|---|---|
| Multi-Reference Parallel | Quick direct shots from independently specified character/scene references; simple prototypes | Two adjacent shots with original identity, environment and one prop; compare continuity and correction locality |
| Multi-Reference Sequential | Successive shots reference preceding frames; proposed for large movement | Same two shots, same model, duration and brief as Parallel if available; compare continuity at cut and whether correction propagates |
| Multi-Grid Storyboard-to-Video (N-Grid) | Preplanned panels to video | Test one limited-motion narrative with authored panels and verify intended panel order/timing; then test more complex action separately |
| Video Reference (Seedance models) | Guide describes using a clip to guide motion/camera | One authorized original motion reference; compare trajectory, scale and action timing to brief, independently from visual style |

Important nuance: the quick table on page 5 recommends N-Grid for comparatively static dialogue, while page 11 describes it as suitable for longer/complex stories and exact transitions. Treat this as documentation ambiguity and test one simple continuity case before drawing a conclusion about action. The guide also advertises up to 20 episodes daily (p.2), very long short-drama script inputs (p.3), and model/version examples (p.4); no throughput, quality, input-limit or current model guarantee inferred. Voice generation may consume extra credits (p.5); estimates are not final charges (p.11). The moderation/review interface (p.8) does not authorize bypassing a rejection; use cleared fictional references and accept an unsupported or rejected route as such.
