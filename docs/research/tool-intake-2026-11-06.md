## Bounded order, not a new production slate

1. **SAND3D-01**: original three-part mechanism; edit/reuse across two cameras, baseline raw bpy. Pass: named parts, stable dimensions, correct pivot, reopen/export and repeat render;6–10s output only when a selected production authorises it.
2. **OPENDIRECTOR-01**:12s authoring/handoff from existing cleared media, no provider calls. Pass: cut/frame timing, audio sync, text, relink and project reopen after one correction; compare existing route.
3. **UCUPAINT-01 / RELIEF-01**: one reusable textured/embossed book prop. Local baseline first; evaluate separately so a successful displacement does not qualify Meshy.
4. **MEGASCANS-01**: one small asset only when it improves a selected set; resolution/storage/licence check before retrieval.
5. **Conditional services**: OMNI-EDIT-01, LUMA-REFRAME-01, TRIPO-CANVAS-01 and HYPER3D-01 need actual free/already-paid entitlement or a separately approved cost cap. One baseline/one candidate/at most one correction. No automatic rerouting to paid API.
