## Primary-source checks and limitations

[Epic's Mac requirements](https://dev.epicgames.com/documentation/unreal-engine/macos-development-requirements-for-unreal-engine)
list 16 GB minimum / 32 GB recommended memory and feature-specific Apple Silicon
limits. This establishes a possible platform, not comfortable operation on the
current machine. Recheck the selected engine release and storage budget first.

[Epic editor scripting](https://dev.epicgames.com/documentation/unreal-engine/scripting-the-unreal-editor-using-python)
places Python in the editor; it is not general gameplay Python at runtime.
[Movie Render Pipeline](https://dev.epicgames.com/documentation/unreal-engine/movie-render-pipeline-in-unreal-engine)
provides a separate cinematic export path. A working editor MCP does not establish
frame-accurate movie export or broad support for every editor action. The tutorial
mentions an Unreal MCP and an all-tool-set plugin but this review did not identify
and audit their exact versions/source/licences. Do not substitute an arbitrary
similarly named repository. The author's linked [starter assets](https://unrealsensei.com/AIStarterAssets)
were not retrievable by web fetch; their reuse rights remain unchecked.

[Unreal licensing](https://www.unrealengine.com/license) has revenue/use-dependent
free and paid categories. It is not permissive OSS; models, marketplace assets,
AI access and plugins have separate terms. Do not label a complete route free
merely because an engine download is accessible. The present test plan buys nothing.

The linked [Grok Bot announcement](https://x.ai/news/introducing-grok-bot)
describes hosted multi-agent work, approval requests and eligible subscriptions
with separate Bot usage. It does not establish that this account has access, that
usage is free, or that the particular six-role city workflow works unattended.
The video's role descriptions (research, hooks, replies, rendering, posting,
revenue tracking) remain descriptions, not independently tested capabilities.
Publishing/replies, account grants and costs retain Framewright's existing gates.
