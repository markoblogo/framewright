## Teardown — active candidate for one mechanism insert

[Repository](https://github.com/elvarofficial/teardown), [README](https://github.com/elvarofficial/teardown/blob/main/README.md), [manifest](https://github.com/elvarofficial/teardown/blob/main/package.json).
MIT, authored for Claude Code; Node>=20, Three.js/esbuild/Playwright; FFmpeg for
capture and standard-library Python for procedural sound. The advertised output
is one offline interactive HTML mechanism and a deterministic recorded tour,
not generic image-to-video or a quadruped locomotion generator. Runtime/geometry/
state/film separation could improve repeatable local inserts. Mac suitability is
plausible from dependencies, not a completed Mac/Codex test or engineering validation.

First test: one fictional dispenser with a visible mounted lever/linkage that
moves one tray, two camera positions,5s repeatable clip, then one timing change.
Check causal linkage, contact, same-state reseek, no panels/cursor in film output,
contrast and style match. Good Dog K06/K07 may use it if the mechanism communicates
control better than the existing Blender route. No requirement to insert a technical
explainer screen. Reuse an example only with licence/provenance retained and after
reading its local dependencies; no wholesale skill installation or copied code now.

## StableGen — conditional prop/scene-texturing candidate

[Repository](https://github.com/sakalond/StableGen), [installation](https://github.com/sakalond/StableGen/wiki/Installation), [rigging](https://github.com/sakalond/StableGen/wiki/Rigging-and-animation).
GPL3 Blender add-on using a local/network ComfyUI backend for projected textures,
mesh generation and rig workflows. Declares Apple Silicon add-on support; Blender
4.2–4.5 or5.1+, explicitly not5.0. That says nothing about whether every backend
model fits this Mac. Installation page estimates roughly10GB to>50GB of models;
TRELLIS.2 uses CUDA extensions, SkinTokens requires NVIDIA. Humanoid retargeting
documentation does not establish a supported dog rig. Individual weight licences
and custom-node dependencies differ from the add-on licence.

First feasible test only after selecting an available compatible backend: one
original crate/dispenser housing →2–3 camera-guided textures → orbit/light change
→ inspect projection seams, baked UV export and reopen. Potential K06/K09 prop,
not a dependency of the current film. Start with an existing small cleared model,
not installing all packages or generating a hero rig. Exact Blender version,
ComfyUI access, model/weight terms, RAM and storage budget are prerequisites.
