## OpenMotion

The [current repository](https://github.com/nexu-io/openmotion) describes reference-led editable graphics, brand kits, MP4 export and shared Motion Packages. Its package validation checks declared files and structure. Automatic import and rendered fidelity are separate claims. Framewright already adopted the [Motion.md contract](openmotion-motion-md-2026-11-17.md) and retained a [bounded local continuation and export](../experiments/openmotion-reuse-2026-11-17.md) at upstream commit `fcbaa2b`. Preserve that version evidence. When a fitting film calls for it, try a new owned title or stat graphic, move its package to a fresh directory, reopen, change a label and export both aspect ratios. Confirm asset and font portability, exact text and unchanged timing. The existing local renderer is the baseline. Keep the reference-media rights and dependency licences with the package.

## Topaz

The [November update](https://www.topazlabs.com/updates/nov2026#more) adds **Wonder 4** and **Image HDR** to Web and Mobile. Wonder 4 combines upscale, denoise and sharpening in one still-image pass. Image HDR produces HDR JPEGs. An HDR display and a separate SDR delivery check matter if the deliverable uses that path. The pricing panels list Starlight Precise 2.6, Starlight Fast 3, Astra 2 and Hyperion 2.5 under video workflows. The November announcement itself gives no new video-restoration evidence for our stack.

**TOPAZ-STILL-01:** on one owned low-resolution plate with meaningful fine detail, compare an equal-resolution Wonder 4 result against local Lanczos scaling. Check exact lettering, face and material detail, edge halos, colour and whether source limits remain visible. Retain both files, model and export settings, account quote and active time. Keep source-quality documentary stills when generated detail would misrepresent an object. Confirm exact access, storage and applicable plan terms before any upload or render.

## Suno MCP

[Suno’s overview](https://suno.com/mcp) gives the official remote endpoint `https://api.suno.com/mcp`. The unauthenticated web request returned 401. The [18 November FAQ](https://help.suno.com/en/articles/14486145) now explicitly includes Free plans, and the [feature guide](https://help.suno.com/en/articles/14551361) mentions stems, MIDI, Sounds, Speech beta, editing and Visuals with plan-specific restrictions. Generation consumes plan credits and saves to the library. Public rollout guidance updates the [existing assessment](suno-mcp-2026-11-02.md). Framewright’s earlier consent flow reported an account-level rollout block, and the current account was not retested. Connector scope includes library and write operations, so use only the operations authorized for the selected task.

**SUNO-MCP-01 remains conditional.** Next useful proof is account access and one authorized library retrieval or download of a cleared track. A future generation test would additionally need a confirmed credit limit, track rights and a cue to score. Keep the [commercial-use guidance](https://help.suno.com/en/articles/9601665) and the actual track creation/download record together. An OAuth grant or a Free plan alone does not clear monetized use.

## Hyper3D

The [Rodin product](https://hyper3d.ai/) covers image/text-to-3D and WorldGen. The [PolyGen API](https://docs.hyper3d.ai/en/api-specification/polygen) documents asynchronous low-poly creation from an existing Rodin task, uploaded mesh, reference images or text. An uploaded mesh can transfer its original textures. API calls require a bearer key with Full API access. The [remote MCP](https://hyper3d.ai/features/mcp) uses browser authorization and the selected workspace’s plan and credits. Whether that MCP exposes PolyGen is unverified.

**HYPER3D-01 follow-up:** tighten the existing [GLB candidate](tool-intake-2026-11-06.md#hyper3d) to one owned textured prop. Prefer testing PolyGen on an existing GLB via the exact entitled route. Compare against local Blender simplification at a matched face budget. Check the silhouette from two camera angles, UV and material transfer, normals, object scale, texture size and file weight after a fresh Blender/Three.js import. If only a Rodin MCP generation route is available, record that as a GLB generation/import test with different inputs and scope. World simulation, rigging and articulated animation stay outside the comparison.

## Ideogram 4.6 and Print on Demand Studio

The [4.6 release](https://ideogram.ai/models/4.6/) and [API model reference](https://developer.ideogram.ai/v2/ideogram-api/models) describe Generate and Precise Edit, optional masking, up to five image references in Generate and up to 4K depending on quality. The vendor cites a multi-step editing benchmark. We would test the actual edit behavior on our layout. Text layer extraction is documented separately in the API reference. It is not implied by a 4.6 image export.

**IDEOGRAM-EDIT-01, first new production-facing candidate:** take one owned product image or cover draft with exact text and a deliberate white margin. Make one masked colour or finish edit. Compare with the existing local compositing baseline at the same display size, then inspect spelling, small type, object silhouette, untouched regions, exact palette and aspect-safe crops. Record actual images, selected settings, cost and revision time. Keep exact publication typography editable in the final assembly. Confirm upload terms, workspace access and quote before the run.

[Print on Demand Studio](https://ideogram.ai/features/print-on-demand-studio/) brings together design, refinement, background removal, resizing and mockups. It could supply one plausible mockup for an original prop listing, a fictional storefront or a poster. Product listings are uploaded separately. Listing research uses signals such as Amazon rank and changes against historical rank. Those signals do not verify unit sales, earnings or commercial demand. Any future print job requires the actual supplier’s dimensions, bleed, colour and rights checks. No store integration or print order is part of this intake.
