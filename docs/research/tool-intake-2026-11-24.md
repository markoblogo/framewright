## Proposed next Radar treatment

Return to Radar #7, Copilot in the browser. Reuse the reviewed landscape pilot,
whose enlarged confirmation was easier to read. Start on the existing synthetic
form, then cut on the click to a short confirmation and a three-state insert:
request prepared, explicitly confirmed, complete. Retain the actual receipt as
the result. Label the reconstruction and make no claim of operating live Copilot.

Try diagram-design on the insert, with the current OpenMotion treatment as the
control. In an 8–10 second silent 16:9 comparison, keep both versions' wording,
timing and source footage identical. The viewer should identify which action
needed confirmation and whether it completed. Retain the winning editable
layout and record the effort to change one label. This can become a reusable
insert for interface explainers. Production awaits selection.
