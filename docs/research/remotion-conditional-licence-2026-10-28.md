# Remotion: source availability and use eligibility — 28 October 2026

Status: current official licence/pricing documentation reviewed. Remotion already
has retained scoped production evidence in Framewright; this is a licence-classification
clarification, not a new runtime test, retrospective rights grant or withdrawal of
that technical evidence.

[Licence](https://github.com/remotion-dev/remotion/blob/main/LICENSE.md) and
[eligibility/pricing](https://www.remotion.dev/docs/license/pricing) distinguish a
Free License for eligible users from Company licensing. Current published criteria
include individuals and small organisations; exact entity/use/version conditions
must be checked before use. The repository also flags a forthcoming licence change
for 5.0, so current `main` is not a substitute for the terms of a pinned runtime.

Classify it as **source-available software under a custom licence**, not as a
permissive OSS dependency. Public source and locally installed software do not
establish this user's eligibility. Paid components, hosted rendering, infrastructure,
templates and media may introduce separate costs/rights. Using it as a parameterised
video executor is different from copying its code into a distributed derivative;
inspect relevant terms for the concrete use.

Current intake policy remains conservative: Remotion's cost facet is `unknown`,
the conditional-authoring recipe appears only when both options are requested,
and free-only omits it. Its provider fee/total stay null. A user-declared subscription
or available account must not bypass the eligibility check. No automatic legal-entity
inference or current paid quote is introduced. A future explicit eligibility record
should bind user/entity, purpose, runtime/terms revision and observation basis; if
those change, recheck it instead of silently carrying free status forward.

Retain Remotion as an optional already-used renderer, with scoped capability evidence
and a separate unresolved use/cost gate. No additional generic render test is needed
merely because this licence note changed. Review eligibility on the next selected
Remotion production; preserve the owner's free/open-source preference and offer
an appropriately qualified alternative where needed.
