# Suno MCP — official connector candidate

2 November 2026. Research only; no connection, OAuth grant, account inspection,
upload, generation, download-credit spend or publication. Extends the existing
Suno music profile, not a second provider or installed Framewright executor.

## Official evidence

The [Suno MCP page](https://suno.com/mcp) publishes the server endpoint
`https://api.suno.com/mcp`. The former is the information page, not the server URL.
The page describes account sign-in/approval without an API key; requests consume
Suno account credits and outputs save to the Suno library. It advertises creation,
audio uploads, Covers/Mashups/Extend and saved Voices. These are vendor-described
features, not an inspected tool schema or successful local operation.

The [Beta FAQ](https://help.suno.com/en/articles/14486145) says all Suno plans,
including Free, can use MCP. The page also advertises early-access registration;
actual rollout/account availability remains to be checked. The
[feature overview](https://help.suno.com/en/articles/14551361) additionally lists
Speech and plan/credit inspection. No specific Speech voice quality, film-duration
control, stem export, file-download tool, async job contract or Codex compatibility
was demonstrated here. Other music-model access through an aggregator is not this
official authenticated connector.

## Rights and file-export boundary

The [Free rights guide](https://help.suno.com/en/articles/9601601) describes daily
50-credit generation and personal/noncommercial use; this is not the observed
balance of the owner's account. A free MCP connection does not grant publication
rights for a commercial deliverable.

[Download guidance](https://help.suno.com/en/articles/13876865) separates generation
credits from downloadable files and gives account-age-dependent trial access.
[Trial guidance](https://help.suno.com/en/articles/13926401) describes up to seven
lifetime trial downloads; these are neither guaranteed remaining quota nor monthly
free exports. Do not assume a library song can be retrieved as a usable local file.

The [paid-rights article](https://help.suno.com/en/articles/9601665) uses download-time
wording, while the [older retroactive-rights FAQ](https://help.suno.com/en/articles/2425729)
says later subscription does not by default clear a song made on Free. These
statements must not be collapsed into a promise that upgrading retroactively clears
an existing track. Resolve the specific track's creation/download plan and current
terms before public/commercial use; keep it internal if eligibility is unresolved.
No subscription purchase or upgrade is proposed for ordinary testing.

## SUNO-MCP-01 — conditional limited trial

Status: **documented connector candidate; access/export/rights gated**.
M4/R05/R09, existing music workflow. Potential use: a fresh instrumental bed for
an approved cue sheet, or one controlled revision of an authorised original track.
Not automatic music for every film, song publishing or voice cloning.

1. Only after owner selection, connect the official server through the host's normal
   sign-in/grant flow. Inspect actual tools, account plan, generation credits,
   download entitlement and approval scope read-only first. Do not copy unverified
   setup commands into global configuration or request unrelated account grants.
2. Agree one original instrumental brief with a 15–20s desired edit window, mood
   progression, no lyrics/vocals and one timeline cue. Exact generated length/BPM
   are requests, not guaranteed controls. Set the maximum attempts and account
   credit cap from an actual quote before submitting; a request may yield multiple
   tracks. No paid top-up, automatic retry or publishing. No private upload needed.
3. If already-permitted quota covers it, one generation; at most one follow-up
   revision with its own cost check. Keep output IDs/receipts and unresolved jobs
   so reconnect/retry cannot silently duplicate spending. This is a proposed
   integration contract, not an implemented idempotency guarantee of Suno MCP.
4. Verify a permitted real audio download, probe duration/format, listen for unwanted
   vocals/artifacts and fit an excerpt under narration. Compare with our available
   local original-score/licensed-stock route for musical usefulness, editability,
   elapsed time, costs and handoff. Save only the selected result and compact notes
   under the storage policy. If export or rights are unavailable, stop at an internal
   listening trial and retain the production fallback.

Exact version, model, actual tool behavior and commercial clearance stay unknown
until a selected trial. No service integration, account access or tested capability
is created by this document. Existing film/SSI no-music requirements stay intact.
