## Delivered behaviour

`trials.py` freezes one bounded capability/question, common source pins, settings,
criteria and limits; it retains the card and comparisons in the existing schema-2
project/journal. A/B packs copy and hash-check selected existing artifacts and add
HTML/Markdown/JSON reviews. Observations, processing time/cost and owner review
remain separate. A failed baseline can be useful evidence; candidate failures,
unknown checks/cost/time and unresolved prerequisites remain visible.

`environment.py` reads a selected requirements manifest, local platform/resources,
explicit program/model availability, optional fixed version/GPU queries and supplied
export/runtime, rights and cost prerequisites. No model is imported and no renderer
is started. Presence, driver hardware, framework support, export success, legal
clearance and authority are distinct. Reports freeze the requirements and source hash.

## Synthetic public-interface proof

The [runnable example](../../examples/trials/README.md) creates original text fixtures,
a deliberately failing baseline and passing candidate, measured marker checks, local
environment evidence and an A/B folder. It stops at `ready_for_owner_review`, without
catalogue promotion or fabricated owner approval. It is not a media-quality test.

Regression coverage includes changed/repinned inputs, copied media changes, latest
pending owner review, duplicate attempts, mismatched sources, missing evidence,
nonfinite measurements, unknown versus zero cost, budget overrun, incomparable
currencies, HTML note escaping, explicit version probes, missing/empty model files,
hash mismatch, GPU not inferred, and refusing overwrite/symlink targets.

## Limits and reuse

Each comparison and its latest review depend on exact retained files. A new revision
or changed copy stales the attempt; a stale newest attempt cannot resurrect an older
acceptance. A fully checked candidate plus actual owner-reported acceptance only
proposes a bounded catalogue update; no provider/feature becomes tested automatically.

This is a software workflow validation, **not another counted final video export**.
No reduced production time, improved naturalness, audience lift or universal tool
compatibility is established. Continue with the [contract and commands](../../skills/video-production-router/references/trials-and-readiness.md)
and the existing experiment queue; do not restart paused productions.
