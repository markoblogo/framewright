# Neubad: poster to character grid

21 November 2026. A bounded editorial treatment comparison inside [Neubad / Paper City](../productions/neubad-paper-city.md). On the same supplied print, compare a luminance-only ramp against a luminance ramp blended with 25% inverted edge map. The same 58×36 landscape grid, Menlo glyph ramp and palette were used. Both treatments produced real local image files and a labelled side-by-side proof.

The luminance-only version had stronger dark detail in the sampled face and became the first character-grid panel. A reversed, edge-assisted version is used for the second print in each pair. The film reveals the character rows over time and shows the source print beside them. Both wide and portrait final files were decoded. This is an authored Pillow conversion of supplied stills.
