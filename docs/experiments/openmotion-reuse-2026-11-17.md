## Quality, resources and limits

Controllability is observed only for this exact copy edit and stale-write refusal.
Encoded readability,motion,drawing stability,artifacts and sound are not assessed from
MCP responses or a package check. There is no owner evaluation or audience result.
If native exports remain incomplete, use the established direct renderer only after
selecting that route explicitly;do not silently report it as OpenMotion native export.

No paid provider/API call;local compute/electricity unpriced. Installation,render wait
and active authoring are different measurements;active labour was not fully timed.
The first default-resource attempt and the changed single-worker attempt remain
separate. This is one trial,not one per aspect,retry or imported asset.

Private retained evidence is under `records/openmotion-adoption-2026-11-17/`:
source/runtime receipts,build logs,MCP trace,exact revisions,export jobs,cancellations,
package checks and final evidence manifest. Production source/material is under
`productions/openmotion-reuse-trial-2026-11-17/`. These paths are relative to the
external studio,not public repository downloads. Source/failed evidence is retained;
no upstream node_modules,media,runtime or copied skill is committed.

The [readable specification](../../skills/video-production-router/references/motion-spec.md)
is the adopted reusable procedure. OpenMotion remains a scoped companion environment.

character acting quality. Quixote remains paused. Blender/direct HyperFrames are
