## Source inspection and GIF treatment

Original GIF600×338,10fps,253frames/25.3s retained. Full contact-sheet inspection
found three scenes, not robot-only footage: robot~0–8.8s,Strachan~8.8–16.7s,
Kallat~16.7–25.3s. An initial snapshot exposed a wrong scene under the robot
caption; source segmentation corrected this before delivery export. This is
a useful regression lesson: inspect the entire clip, not just its first frame.

Each scene now accompanies its own work. Robot excerpt is deliberately looped
with0.35s crossfade. Source photographs are retained without regeneration.
GIF processing uses FFmpeg hqdn3d1:1:0:0,minterpolate30fps/MCI/AOBMC/bidir,
Lanczos1200×676 and mild unsharp0.35. A4s probe and sampled edges were inspected.
This adds interpolated intermediate frames and improves presentation; it cannot
recover missing source detail or prove a measurable perceptual-quality gain.
Original remains available. Owner motion/artistic review still required.
