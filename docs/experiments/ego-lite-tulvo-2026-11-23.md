# Ego Lite for browser-based production

23 November 2026. Owner retained Ego Lite in the arsenal for web-product
testing and screen-recorded demos. One macOS probe on Ego Lite 0.6.3.17
with a separate browser profile, no Chrome import into that profile,
and owner-completed Google sign-in.

In Tulvo, a synthetic enquiry was created on a private board in a
separate workspace. It changed from New inquiry to Brief reviewed and
retained that stage after reload. The screen recorder was macOS native
window recording. The first attempt targeted a hidden window and returned
black video. Recording the foreground full-screen window, then cropping
out browser chrome, yielded a checked 7.27 s 1280×720 MP4.

In Google AI Studio, the browser's native media menu downloaded one
existing synthetic 10 s MP4 attachment. The local 640×360 H.264/AAC file
fully decoded. This establishes that download route for this attachment.
New Veo exports, Ego's CLI and video capture inside Ego remain untested.
Elapsed working time and relative speed against Chrome were not measured.
Raw captures and download evidence remain in the private production.
