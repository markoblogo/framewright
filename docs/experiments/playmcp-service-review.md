## What the tool trials establish

- **Awwwards-mcp 1.9.0 — partial component only.** Expanded upstream `recordSiteMotion` use to public home, Create, challenge, profile/feed pages. The injected launcher uses installed Chrome and native FFmpeg; all generic clicks are suppressed. No account cookies, default MCP startup, background index or search was exercised. Missing helper/browser-path failures, strip padding and event-clock limits are retained. Different viewports and output contracts prevent a speed/quality superiority claim.
- **Hyperframes 0.8.183 — scoped render and audio FX.** Upgraded from 0.8.174 and rechecked the composition. Local core voiceover carve applied three spectral cuts and a 409-point gain envelope at strength 0.40. Encoded technical checks passed; this is not automatic subjective mix judgment. Native capture supplied readable static plates.
- **mlx-whisper — human-English follow-up.** Retained tiny.en was used on owner speech and pickups with source-time records and editorial corrections. This does not qualify unattended captions, other languages or acoustic review.

Original local instrumental music and an already-admitted CC0 DJT4NN3R transition sound were reused. There was no new Openverse search or model download. ## Reusable production method

1. Accept the operator take, retain source/pickup edit decisions and lock shot timing to it.
2. Explain the real product before personal examples; preserve scripted-gameplay and fixed-seed disclosures.
3. Freeze readable interface frames when useful; distinguish illustrations from game capture.
4. Keep itemised costs, lower bounds, technical checks and human acceptance separate.
5. Check the composition, preview and decoded output; prepare a local kit, then record the supplied publication URL against the retained export.

Generic media-perception models, other world providers, full Awwwards MCP and audience outcomes remain unqualified. The Jekyll Short stays cancelled; its standalone game overview is deferred. The [next production cycle](../next-cycle.md) pauses SSI and starts Pocket OS intake.
