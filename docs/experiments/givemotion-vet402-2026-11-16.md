The package reported zero dependencies; no copied upstream skill/source entered Git. Runtime, npm/engine/parts caches and all outputs reside on Work. Existing Chrome executable remains at its prior internal location; it was reused, not downloaded.

Executed: native HTML/SVG timelines, sequential local scene clips, transform/opacity animation, deterministic frame callbacks, hand-drawn SVG outline, still PNG covers, four-second MP4 proof and full52s/24fps native1920x1080 and1080x1920 exports. Actual software encoder libx264; no hardware acceleration claim. A successful render is not owner creative approval. No API key, model generation or paid provider call.

The trial found an authoring trap: animating an SVG group that also supplies its base translation moved artwork to the origin. An outer position wrapper and inner animation group resolved the encoded defect. The automatic check caught overlaps/tiny labels/still intervals; manual reduced/native inspection found remaining layout defects and corrections. Check success alone did not qualify motion/readability. Frame-based abstract motion is within this trial; anatomy, acting, generated footage, generic unattended editing and transfer to another operator are not tested.

Retain reusable authoring sources, engine version, exact commands, selected masters/covers, script/voice and receipts in the private film directory. Conditional use: code-native explainers, animated editorial diagrams and readable receipt/document stories. It is an animation/export engine, not a source of convincing character performance. One executed trial; aspect variants, proof, full exports and repairs are not extra trials. At the prepared checkpoint the film awaited owner review.
