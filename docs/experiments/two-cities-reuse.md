## What is reused and what is new

Baseline: accepted [Kazan rooftop film](kazan-rooftop.md). Reused supplied media,
original Kazan instrumental score, cached Supertonic-3 M1 voice recipe and existing
blue/black/white typography principles. New: comparison script, shot/crop data and
an authored FFmpeg assembler. This is not a replay of the old HyperFrames renderer
or proof that all inherited styling already forms a qualified series template.

[Source recipe](../../examples/production-reuse/README.md) separates immutable
appearance/assembly code from private copy, media, voice and duration data. One
plan produces both aspects. Six local title controls exercised short copy, long
copy and missing optional subtitle across both aspects. Font size wraps/reduces
within a checked safe area. Photos retain original pixels with a slow camera
crop; source video is newly edited and its audio discarded. Narration and reused
score are mixed separately. Cropping and final listening still need owner review.

## Measurements and failures

[Receipt](../../experiments/2026-10-30/r04-two-cities-reuse.json) records each
successful scripted shot/assembly/decode wall time separately. These exclude
agent authoring, retries, voice setup and the horizontal48kHz delivery conversion;
not total operator effort. Baseline effort was not measured, so labour savings
and RV01 completion are not established.

Two authored-recipe failures are retained privately: FFmpeg rejected `.2` as a
fade duration, then relative concat paths were resolved twice. Corrected syntax
and absolute output paths; new output revisions preserve failed runs. Added
per-stage progress receipts. These are our assembler defects, not upstream-tool
failures. Horizontal delivery audio was resampled from96kHz to48kHz; portrait
assembly now explicitly requests48kHz.
