## Production and bounded trial

104.43s,1920×1080/30fps, eleven voice-led beats. Local Supertonic3 M1 narration
uses retained cached weights with manifest checks,2 inference threads and no
model download. An existing original instrumental from MN7R is reused quietly;
no scientist's voice is cloned and no animal/operation sounds are fabricated.

PixiJS8.6.6/MIT is a new narrow trial: two raster sources, absolute-time camera
position/scale, actual screenshot crops and annotations. HyperFrames0.8.183
provides the timeline/preview/local render. GSAP drives one paused clock. The
registry camera-depth-stack was inspected but does not match source-image
exploration; a custom source-camera was the selected test. There is no depth
inference, photogrammetry,3D reconstruction, physical surgery simulation or
Matter.js test in this scope.

Two separate CLI snapshot invocations produced matching decoded pixels for all
four sampled frames, including the tool-added ending sample. Hardware context:
Apple M4 / ANGLE Metal. This is repeatability on this environment, not portability
across GPUs or a whole PixiJS qualification. Owner accepted the editable preview;
encoded delivery still requires identity/duration/decode checks. Motion quality,
voice naturalness and audience results are separate from JSON/pixel checks.

One local export worker/low-memory mode is used. No concurrent heavy benchmark,
cloud render, paid generator or new subscription. Provider usage query returned
unknown; it is not recorded as zero provider balance. The actual chosen execution
is local. Media, models, vendor bundles and caches remain outside Git.
