# VOICE-EXPORT-01 — tablet browser to Mac, one completed probe

14 November 2026. The owner requested this test after PR71 was merged, without
asking them to download the speech. **One short English Fola export and transfer
completed with no owner clicks/downloads during the probe.** This is bounded workflow
evidence on the prepared tablet, not a completed AUTOPROD film or general autonomy.

## Actual route

- The already-authorised Xiaomi Redmi Pad Pro (2405CRPFDG, Android16) was connected
  over USB and Chrome already had the owner's Google session. AI Studio's normal
  `generate-speech` page loaded. No new login, app install, purchase or API key was
  required. The UI showed Gemini3.8 Flash TTS and no API key selected; monetary
  cost was not displayed, so no zero-cost claim is made.
- Created one dialog and entered an original 32-word English export-test script.
  Fola was the current preset. Attempts to open the voice picker did not establish
  a changed preset; Knox selection is **not** qualified by this trial.
- Touch actions did not produce observable voice-picker/run/download state changes.
  Used the UI's displayed **Ctrl+Enter** shortcut; one completed11-second result
  appeared. Keyboard entry worked. Do not treat a logged tap as successful UI action.
- Hid the on-screen keyboard. Used Tab while inspecting the actual focused controls,
  then Enter on **Download**. A real WAV appeared in Android Downloads. Do not hard-code
  the observed Tab count: focus order/state must be checked on each run.
- Transferred that exact newly created file to Work with existing authorised USB/ADB.
  Tablet hashes before/after transfer and the Mac hash match. Other downloads, gallery
  material, InShot drafts and account settings were preserved.

## Reuse and remaining limits

Use the supported keyboard route as the next candidate for this prepared tablet;
verify the actual file each time. At that probe checkpoint, setup resilience, long scripts, Ukrainian,
Knox selection, multi-speaker output and repeated production were untested. Later
bounded production evidence is recorded below; it does not widen the probe itself. This
English take does not replace the [Ukrainian Fola listening preference](../ukrainian-voice-baseline.md)
or [voice policy](../voice-selection.md). A good export cannot establish a natural
performance; new takes still need their relevant listening review.

At the 14 November probe checkpoint, [AUTOPROD-01](autonomous-production-pilot.md)
had no full-film tests started. This proof removed the manual-download dependency
for **this one short single-speaker case**; it did not by itself qualify whole-film
automation. Mac development and Android-app alternatives were not attempted.
