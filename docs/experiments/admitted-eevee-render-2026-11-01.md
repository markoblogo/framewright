# Блок 2 — реальный Eevee-рендер через исполнитель

1 ноября2026 · R03/M2 · [машиночитаемый результат](../../experiments/2026-11-01/admitted-eevee-render.json)
· [воспроизводимая проба](../../examples/last-seed/run_admitted_probe.py).

## Результат

Сохранённая производственная сцена The Last Seed (исправленный pilot scene-v4)
прошла выбранный маршрут → допуск → реальный Blender → проверку MP4 → сохранение
результата в отдельном внутреннем проекте. Принятый фильм и его checkpoint не
открывались для записи. Это ограниченная проверка кадра, не повтор всего фильма.

Исполнитель теперь поддерживает явный `BLENDER_EEVEE_NEXT / AUTO` наряду с
`CYCLES / CPU`. В Eevee `samples` задаёт `taa_render_samples`, а `seed` должен быть0
и не используется. Автоматической замены движка нет. Реальный движок, запрос,
версия и build Blender сохраняются в state.json. AUTO означает штатный графический
backend Blender, а не подтверждённый CPU-режим или гарантию совместимости GPU.
Неподдерживаемый build/sample control завершает работу ошибкой.

Все прежние ограничения источников, симуляций, pinned worker/runtime, диапазона,
времени, размера папки, отдельного звука и проверки выходов сохранены. Старые
контракты с прежним worker не приобретают новое разрешение: нужен новый выбор.

Blender4.5.15 LTS ARM64, build5afeabba6097;480×270,24fps,8samples. Фиксированная
объявленная камера и сохранённые действия/материалы сцены; оригинальный WAV.
Публичные кадры считаются от0, правая граница исключена.

## Сбой и восстановление

Проба послала SIGTERM только собственному executor после записи реального
Blender render-log. Управляемая группа остановлена; папка перестала изменяться,
ожидаемый output остался незарегистрированным. Журнал содержит failed attempt.
Повтор той же команды без `--retry-of` отклонён и не создал новую попытку.
Явный повтор с ID failed attempt сохранил новый результат `review_pending`.
Задания остались planned: технический результат не означает принятия.

В этом native-тесте исход сбоя был известен. Ветка unresolved/reconcile после
неоднозначного обрыва отдельно этим запуском не подтверждалась; она остаётся
отдельным механизмом с прежними тестами, без автоматического повторения.

## Ошибки подготовки сохранены

1. Два первых допуска остановились без запуска рендера: проверка версии Blender
   на внешнем диске не уложилась в5с. Отдельный замер:14.43с. Для фиксированной
   allowlisted команды Blender теперь30с; остальные версии по-прежнему5с.
   Истёкший таймаут остаётся unknown и блокирует запуск, а не считается успехом.
2. Ограниченный native-запуск упал SIGSEGV при инициализации Metal до кадра.
   Нормальный графический доступ macOS устранил этот конкретный стартовый сбой.
3. Ранняя сцена содержала старый конфликт имени Rim между mesh и светом.
   Worker корректно отказал, вместо пропуска проверки. Для нового контракта взяты
   исправленная scene-v4 и соответствующий shot-spec; старый источник не менялся.

Логи, исходы, контракты, PNG/PCM/state и failed-папки сохранены локально вне Git.
Медиа, бинарник Blender и абсолютные частные пути в публичный результат не входят.

## Граница и следующий шаг

Ограниченный Eevee saved-shot разрыв закрыт для этого build/Mac/сцены. Не заявлены
полноценный монтаж фильма через исполнитель, финальное разрешение, произвольные
camera rigs/симуляции, межплатформенная повторяемость или качество звука/истории.
Прежние ручные этапы The Last Seed остаются историческими ручными этапами.

Далее — сопоставить оставшиеся требования REL-A с фактическими доказательствами
и собрать предрелизный срез. Релиз, коммит и push в этом проходе не выполняются.

## Проверки реализации

56 связанных тестов прошли: saved shots8, environment8, saved-shot executor10,
admission13 и основной executor17. В том числе явный Eevee-контракт, отказ при
неверном device/seed,30с version-query с сохранением unknown при таймауте,
проверки прерывания/лимитов и защиты повторов. Проверка каталога/схем/локальных
ссылок прошла на локальной копии с побайтово сверенными97актуальными файлами
источников и этого прохода; actual Blender trial использовал исходный checkout.
Это структурные/программные проверки, не model evaluation. Полный suite/CI
не запускались; прежний статус текущих исходников not_evaluated сохранён.
