## What actually changed

- **Resources:** optional host and executor-owned worker observations, with unknown
  metrics and bounded root/child coverage. Existing total-RAM checks keep their
  meaning. Actual macOS arm64 trial used psutil7.2.0 in a private isolated environment
  and one1.2s synthetic child, not a renderer/model. Eleven samples recorded a sampled
  root RSS peak of18006016bytes. Available memory was observed; swap/child-tree access
  was partial. Initial restricted child enumeration produced no samples; a failing
  regression demonstrated the gap and root-only fallback preserved useful observations
  without hiding the missing child coverage. psutil absence was separately exercised.
- **Costs:** append-only exact-decimal events inside the existing schema-v2 project,
  with cap, estimate, reservation, usage, unknown outcome, settlement, adjustment and
  explicit release. Source receipt deduplication, tags, separate currencies/credits,
  late settlement, refunds, conflicting duplicates and cap refusal have synthetic
  controls. No real invoice importer, FX map, financial authority or provider
  enforcement is claimed. Ledger caps are not yet paid-executor admission.
- **Recovery:** intent is durably saved before local dispatch. Interrupted intent
  survives process reload and blocks execution, status/brief and completion diagnosis.
  Explicit retained reconciliation evidence and explicit retry selection are required.
  Changed retry settings/pins are rejected. Production remains separate from review;
  no creative/listening acceptance is inherited. Tests exercise a deliberately
  unsubmitted intent, known local worker failure and repeated command invocations.
  They do not prove external API idempotency or recovery after a provider accepted
  a remote job. No LangGraph migration was needed.
- **Decisions:** deterministic assertion plumbing for the existing six contracts,
  with compliant/violating synthetic controls, altered answers, missing captures and
  incomplete traces. Semantic review stays pending and model qualification false.
  This is not a new agent evaluation, Promptfoo trial or better routing score.
