## Canva Craft — bounded comparison candidate, 2026-10-26

Owner-selected test: **one 16:9 cover with an exact English title → reduced-size
readability check → one focused revision → separate Magic Layers and short-animation
checks**. Compare with our current method on quality, controllability, time and cost.
Before a trial, confirm the actual model and available allowance. No generation,
credit spend, account grant, upload or production test has run; retention is not
execution/publication authority. Subject and exact title remain to be selected.

[Announcement](https://www.canva.com/newsroom/news/canva-craft/) describes Canva's
design-oriented image model, up to 2K, composition/text planning and potential
editable-element conversion through Magic Layers. These are vendor claims, not our
qualified results; leaderboard rankings are not production/audience evidence.
Reference-image capabilities and editing claims must be checked for the exact path.
Craft is an image model, not a video renderer or natural-character animation tool.

[Generation API documentation](https://www.canva.dev/docs/apps/rest-apis/reference/generations/)
and [request reference](https://www.canva.dev/docs/apps/rest-apis/reference/generations/create-image-generation-job/)
document explicit model `craft_v1_2k`, preview API status and use of the user's AI
credits. Without a model pin, Canva can choose another model. The session's inspected
Canva generate-image tool exposes no model selector; using it alone cannot establish
that Craft served the request. The announcement marks Craft MCP availability as
coming soon. Recheck current capability/model evidence before testing; never count
an unidentified or substituted generator as a Craft pass.

Trial controls: use an original non-sensitive concept and the same approved English
title/brief for comparison. Retain model/API or UI evidence, account allowance before/
after, prompts, output dimensions, generation/revision time and manual correction
effort. Inspect the complete title for omissions/spelling, framing and hierarchy at
full and thumbnail size. On the one revision, preserve chosen composition/subject
and document collateral changes. Owner preference is separate from technical checks.

Only then test Magic Layers separately: inspect text editability, subject/background
separation, masks, missing content and halos. Retain an untouched image. Animate a
short fragment through the selected existing renderer or a separately inspected
Canva path; inspect encoded motion, layer edges and final text. Image quality does
not qualify layers, export or animation. Record blocked access/plan/model identity
as unresolved rather than falling back silently. Review current service/asset/output
terms; source/media rights remain independent. No new automatic provider admitted.

Editor MCP is conditional afterward, Snapchat publication a separate future experiment.
All stages documentation-reviewed only; no installation, connection or capture run.
