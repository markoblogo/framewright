# Selection audit — 2026-10-14

The earlier task table recommended one route for a whole film. It did not expose
per-effect evidence, style affordances, language limits or a mixed block timeline.
The initial release added an eight-tool registry, a generated feature matrix and a standalone
offline block/layer planner. Profiles cite upstream sources and distinguish local
experiments from documented capability, retained failures and unknowns.

Selection is input-compatible first, requested effects/deliverables next, local evidence strength, style preference then
the task default. Explicit tool choices survive incompatible inputs as blocked plans.
Companions supply missing features only when their inputs fit. Paid capabilities
are excluded by default. Known voice languages, vertical scope and exact frame timing
are explicit. Unknown physics cannot become a supported feature through wording.

The unit suite checks those decisions; it does not evaluate an agent or prove a
new mixed pipeline. The reference project closes the first-result gap with shared
source and commands. It has not been re-rendered on a clean machine after the lint
dependency repair. No time/cost advantage or universal reproducibility is claimed.

Bounded router decision checks are retained in the
[behavioural report](router-evaluation.md). The latest complete source passes 52/52
under protocol v3 with 22/22 blind controls. The earlier 43/46 and
first-exposure 9/12 remain unchanged: a [versioned diagnosis](grading-v3.md) corrects
source-comparison, singing-alternative and comparison-stop criteria, plus the
router's comparison/production instruction conflict, explicit native-PNG legibility
and complete permission context for grading. This is development/regression
coverage, not unseen transfer or a causal improvement score. Rendering and real
permissions remain separate scopes.

Release 0.1.1 resolves companion dependencies to a fixed point in canonical feature
order. Equivalent requirement arrays have equivalent tool coverage; requested native
stills influence the primary choice instead of falling through to video extraction.

## Unreleased correction

Hyperframes stills displaced tested Brag + FFmpeg extraction, and sound-layer's
documented normalization displaced tested FFmpeg normalization. The new solver
compares complete feasible chains: requirement coverage, then tested-feature
coverage, then fewer tools, then style/default preferences. Each feature uses the
strongest eligible provider even when a selected tool also documents it. Finishers
cannot establish their own picture input. Regression tests retain both examples
and requirement permutations.

reported separately above. See the
