# Framewright 0.9.0 — Studio workflows, review and tablet editing

Experimental prerelease for the agent-and-owner studio. This consolidation brings the production methods and local helpers developed since0.8.0 into one checked router package and source snapshot.

## What is useful

- **Review and recover the selected work.** The loopback preview server supports forward/backward media seeking and confines reads to the explicit review directory. Production checkpoints, source pins and bounded revisions keep accepted work separate from new candidates.
- **Connect production with Radar.** File-based status exchange, acknowledgement and duplicate handling support the existing owner-approved workflow. The configured case flow sends YouTube publication links; it does not choose ideas, generate films or publish autonomously.
- **Choose and reuse a suitable production method.** Case-informed proposals, separate aspect compositions and centre-safe portrait cropping have actual production records. Natural Knox/Fola voices are retained where accepted; the mechanical local voice is a reserve. Measured rendering phases do not establish total labour or monetary savings.
- **Use a physical tablet for bounded finishing.** InShot video/photo/collage fixture exports and the accepted Babylon tour show one prepared Mac/Android route. VLC local playback and media-key seeking were observed. LocalSend achieved no transfer on the tested network; KORG remains separately deferred. Those limits travel with the results.

The source also retains recent fiction, science, browser-world and client-pitch recipes, tool research for current and future hardware, publication-package conventions, the FW identity and visitor-refreshed site. Catalogue entries are not universally qualified tools.

## Compatibility and upgrade

The core remains standard-library Python; CI checks Python3.12. Renderers, editors, Android hardware and provider accounts have their own dependencies and terms. They are optional production choices, not bundled executables or a hosted service.

No project-data migration is introduced by this release preparation. Back up the installed router folder, replace that skill copy with the release ZIP, and preserve private projects, source pins, accepted masters and journals. Owner-specific Work-volume paths in case records describe this studio; other users choose their own storage. Existing Radar integration remains separately configured and does not turn on from installing the skill.

## Known boundaries

Framewright is an experimental methods/skills library operated by an agent and a person. Stable general character rigs/contact, whole-route unattended execution, paid-provider reconciliation, automatic social publication and independent clean-machine operation are unproven. M6/REL-D transfer remains parallel work triggered by a real need, not a completed milestone or a prerequisite for this consolidation.

Babylon capture was roughly7–12fps; Mac interpolation and1080p export do not add captured detail. InShot endpoint-frame parity, unexecuted AI functions and native editable-project transfer remain open. No new model-routing qualification, asset clearance, audience growth, revenue or general cost-saving claim follows from software checks or owner-supplied publication URLs. SSI, RUN outdoor testing and paused Quixote keep their own next steps.
