# Research footage + animated mechanism

A bounded repeat of the [short-research route](short-research-production.md), demonstrated by [Feather Star](../productions/feather-star-swimmer.md), not a general renderer qualification.

1. Freeze the viewer question, primary paper, precise result and limitations. Prefer original supplementary movies with inspectable rights over a reposted compilation. Exclude third-party inserts unless separately cleared.
2. Retain original framing, scale/speed labels and source hashes. Replace source audio when the intended soundtrack is original. Do not infer capture speed from unusual container metadata.
3. Approve one 15–20-second pilot. Reuse its unchanged speech/model/runtime; add measured tail phrases only. Alternate useful demonstrations with a diagram when narration changes the mechanism or mode—not merely on an arbitrary timer.
4. Make action agree with speech: coordinated/individual/alternating inputs must affect traces and geometry consistently; an off state must stop visible actuation. Keep a beat-to-action checklist. Illustrative geometry is not physics validation.
5. Assert each clip's exact output frame count, then decode the assembled film. Check boundary frames and caption placement, native seeking, listening and creative acceptance separately. Package direct files and one readable copy page; record publication and Radar delivery separately from performance.

## Reuse without Framewright

The same process works with a source/rights sheet, timed script, retained WAV stems, an editor or Python/Pillow/FFmpeg scene, exact frame-duration checks and a local HTTP server supporting byte ranges. A spreadsheet can record approvals and revisions. Framewright supplies the version-bound project journal, final selection and optional Radar exchange; neither route makes technical QA equivalent to owner acceptance.

## Limits and next fitting checks

The current render's clip cache compares frame counts only: after changing any source/range/transform, invalidate that derived clip explicitly. A future bounded improvement may key cache entries by source hash, range, transform, FPS and expected frames. That helper is not implemented or qualified by this film. Do not rerender or start a test solely to close this case.

The full renderer reads the accepted pilot MP4 as an input; it is not disposable just because a full master exists. Preserve its source-hook and speech dependencies. Remove unused archive copies only after selected original members hash-match retained files. Record removed availability honestly.

Keep synthetic speech disclosure, research attribution, scientific limits and viewer-facing claims. A title/thumbnail is a hypothesis, not evidence of CTR, retention, revenue or time saved. This recipe does not establish independent operator transfer or a complete analytics feedback loop.
