# Preview a native edit before committing to a full render

Use when several generated or original clips exist but their order, holds or sound
connection still need review. A timeline preview can expose an edit problem before
another full-film export. It does not guarantee free generation, no export charge
or a saving in total active work.

## Repeatable route

1. Pin the original clips, orientation, frame rate, sound sources and intended
   action. Agree what the audience should understand, not only a tool trial.
2. Assemble a short native timeline. Compare source order, meaningful holds and
   audio cues. Keep the editable project and a baseline export.
3. Correct only the actual defect: map changed resources/placements, timing and
   protected picture/audio. Verify contact in the source, not by hiding collision.
4. Save, stop/reopen in the same workspace and verify documents/assets/canvas.
   Export real MP4 in each intended aspect; inspect decode, seeking, source order,
   cue onset, text/crops and adjacent context. Test transfer elsewhere separately.
5. Build a full-film beat plan with changes in action, framing, evidence or sound.
   Preserve natural narration timing, continuous motivated music/ambience and
   readable source labels; finish/export and obtain whole-film listening/creative
   acceptance. Keep exact selected masters, packages and indispensable dependencies;
   retire only hash-inventoried rebuildable caches.

**With Framewright:** use its existing brief/journal/revision records to retain
inputs, protected invariants, decisions and output-specific checks. The agent and
human still operate/review the editor; no general native-editor renderer adapter
was added. **Without Framewright:** use a folder manifest, scene/EDL spreadsheet,
versioned native editor project, change log and the same export checks. This
written alternative has not been reproduced by another operator.

## Observed example and boundaries

[Preview the Cut](../productions/reverie-playall-opendirector.md) tested OpenDirector
0.1.2 on a three-clip/six-placement fixture, revision, exact same-workspace cold
reopen and native11.75s exports. The89.92s owner-accepted films use Blender/FFmpeg
finishing. Native core is an insert, not evidence that OpenDirector authored the
whole film. Retained cues pass within one frame; no cross-machine import, speed
ramp, large-project or general codec qualification. Source720class detail is not
made native1080 by a larger delivery raster. Captions are authored/pause-mapped,
not forced alignment. Vendor Reverie credit claims are not our measured savings.

Use the existing Blender/FFmpeg route as fallback. A beautiful pilot does not
validate an entire long hold. Tool novelty, research entries, publication URLs and
routine QA do not add new film/trial counts or demonstrate audience success.
