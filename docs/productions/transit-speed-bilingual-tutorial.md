## Reusable method

Capture the product in a synthetic-data demo. Use static context images with
camera moves, and a short 3D cutaway to explain a stock transfer. Mask device
inserts to the screen shape. Enlarge workflow evidence where the viewer needs
to read it. Use a centred opening title and closing destination and credit.

Cut the 17 scenes against both narrations on a single picture timeline. Remove
music-only static holds and retime the voice takes gently with pitch preserved.
Time each subtitle file against its final narration. The v4 review cut ran
5:58, down from 8:40. Keep punctuation, checks, and subtitles specific to each
language while retaining the same product picture.
