## Local file check

Both synthetic packages contain byte-identical video and the same filenames.
A separate approved SHA-256 manifest checks each file. In two runs per package,
both video files matched. A's subtitle matched the approved Friday line, and
B's stale Thursday subtitle failed both times. The terminal sequence in the
film replays the verifier's actual output. The client preview is a
reenactment. [GitHub's public-preview announcement](https://github.blog/changelog/2026-11-17-github-copilot-evals-is-now-in-public-preview/)
provides context. The production did not execute Copilot Evals or an agent.

felt like a static picture. The owner found the revised silent action

diverging paths for the two verdicts. GiveMotion 0.1.6 drives these beats with
