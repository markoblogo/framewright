пройденных работ и инструкции, а новые опыты связывать с недостающими примерами.
Рабочая база уже создана: [оглавление](book/outline.md), [три разбора](book/README.md),
[рабочие формы](book/templates.md), [карта пробелов](book/coverage.md).
Полная рукопись и публикация книги не начаты.

Книга о видеопроизводстве с ИИ в стиле Framewright. **С Framewright и без него —
два обязательных маршрута каждой основной темы.** Проект остаётся полноценным
примером реализации; читатель также получает переносимый способ работы.
Оглавление строится по пути производства, инструменты занимают своё место в примерах.

## Что означает маячок

Это предложенный редакционный ориентир «есть чему учить, на чём показывать и как
проверить понятность». Три разных работы — разумный начальный набор, не магическое
число. Посты, видео, инструменты и просмотры не складываются в процент готовности.
Теперь оглавление уже подготовлено; следующий сигнал — можно предложить автору
пробную главу для проверки изложения. Готовность всей книги будет отдельным этапом.

| Условие | Текущее положение |
| --- | --- |
| Понятный читатель, тема и структура | Зафиксированы; оглавление10глав — рабочий проект, ещё не авторски утверждённая структура |
| Несколько полных разборов | P01/P02/P03 оформлены: задача, процесс, ошибки, правки, результат, два маршрута и упражнение; требуется редакционное прочтение |
| Самостоятельное повторение | Инструкции двух маршрутов написаны; отдельный проход по ним ещё не выполнен (G01) |
| Исправление и повторное использование | Подтверждённые узкие примеры: правки фотофильма/собаки, серия SSI, внутренний Blender replay; новые ограничения сохранены |
| Материалы и иллюстрации | Источники/главы/пробелы связаны; частные ассеты доступны не все, права на конкретные книжные иллюстрации ещё нужно оформить |

Статус: **outline_and_case_docs_prepared; reader_reproduction_and_editorial_review_pending**.
При достаточном материале для одной выбранной главы можно предложить её пробную
редакцию автору; не нужно закрывать все G01–G10 ради первой главы. Невыполненный опыт
ограничивает соответствующую тему, а не всю книгу. Написание глав не запускается
автоматически по расписанию постов.

## Постоянное пополнение

Один согласованный продакшен → запись фактов/решений → полезный приём в продукте →
учебный разбор → английский пост → материал главы. [Регламент](book/README.md)
отделяет историю выполненной работы от новой непроверенной инструкции.

Посты [еженедельной серии](editorial/README.md) — источники объяснений и примеров.
Автор присылает ссылки после публикации; записываем их у соответствующих выпусков
с происхождением `owner_provided_url`, не приписывая независимую проверку/метрики.
Для книги посты надо проверить, убрать повторы, показать оба маршрута и оформить
права на цитаты/иллюстрации. Метаданные Book Readiness Radar помогают найти материал;
внешний Radar этой записью не подключается.

При новом доказательстве обновить [индекс](book/index.json) и конкретный пробел,
сохранить ограничение и сообщить о существенном изменении готовности. Ни новая
публикация, ни число постов сами по себе не утверждают главу или книгу.
