and a release. Baseline: `cc67a23758b667d76d114f608ee9282d974fd464`, matching
origin/main at preflight. Local changes were preserved; no existing public tag or
archive is overwritten. Target: reviewed merge commit, `v0.4.0` experimental prerelease.

## Scope

New source-pinned experiment/readiness utilities, bounded Blender shot execution,
versioned passports, tests and installed-package smoke. Current production records
cover 40 final exports; Blender/internal controls are not extra final films. Book
and editorial documentation includes a 10-chapter outline, three dual-route worked
cases, 10 evidence gaps and an English studio-post draft with metadata/cover receipt.
The blog draft's source is part of this authorised repository publication; CMS
publication remains separate. Its generated cover stays in the private delivery.

The archive contains the standalone router skill only, not Blender, third-party
models, media, example scene binaries, private journals or the owner's automation.
The Git tag additionally contains authored examples and documentation. The existing
weekly Codex heartbeat is account-local; cloning/installing the skill creates no job.

## Verification contract

`python3 scripts/check.py --scope capture` is the final offline gate: complete unit
suite, historical router/storyboard evidence integrity, current unqualified source
inventory, links/catalogue, generated matrix and temporary standalone archive smoke.
Package smoke includes `environment.py`, `trials.py`, `passports.py` and `shots.py`
help/import plus existing project/planning checks. It runs no Blender render/model call.
Final local result: **360 tests, zero failures, one skip** (186.934s). Retained
router/storyboard packet checks, links/catalogue, generated reference and standalone
v0.4.0 package smoke passed. The archive imported/help-checked all four new public
helpers outside the checkout. No model/renderer call ran during the release gate.
[Sanitised result](../experiments/2026-10-26/evidence/release-0.4.0.json).

Public release proof is recorded in the GitHub release notes after verifying the
merged commit, tag target, CI and unauthenticated archive/checksum downloads. Local
build success alone does not establish that proof. No application deployment,
website viewport test or DNS change applies to this methods/CLI package.
