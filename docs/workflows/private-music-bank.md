# Private music bank — first real use

2026-10-17. The owner selected one local folder containing two music files and
explicitly permitted reuse in this game and as backgrounds for other videos.
This is a reusable personal collection,not a disposable game asset folder.

The existing `library.py` scanned exactly that folder:2 tracks,0 probe errors.
The private index retains durations,codec/sample rate/channels,bytes,hashes and
source provenance. Original files were not changed or moved. Owner reuse grants
were annotated separately;embedded Suno provenance is retained,not treated as
independent provider-licence verification or public-domain status. Mood,genre and
exact BPM remain unqualified.

A commercial-use26s search rechecked both hashes,returned2 candidates with no file
problems,and retained `publication_authorized:false`. Catalogue matching does not
authorise a publication or prove a useful trim/loop. This is one macOS library
trial,not semantic music search or a portable licensed asset package.

For [Decaf Protocol](../experiments/playmcp-coffee-showdown.md),a26s two-source edit
was made with a150ms crossfade and end fade,then normalized. Only that selected
excerpt was uploaded for PlayMCP analysis and stem playback;the full source files,
private index,embedded metadata and folder paths stay outside Git/cloud indexing.

For the next video:rescan the selected folder,filter by required duration and
recorded rights,listen to candidates,then retain the selected file hash,source
intervals,gain and fade decisions in the production checkpoint. No background
scanning,automatic uploads,unreviewed mood classification or blanket publishing.
