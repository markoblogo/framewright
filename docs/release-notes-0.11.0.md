# Framewright 0.11.0 — repeatable editorial and series production

Experimental prerelease of the Framewright router and methods library. See [GitHub Releases](https://github.com/markoblogo/framewright/releases) for published builds and checksums.

## What changed

- **Choose tools by the job.** [Ranking profiles](../skills/video-production-router/references/arsenal-search.md) cover editorial graphics, local English narration, editable montage and portrait adaptation. Tested tools have scoped evidence and fallbacks. Untested tools stay in a separate queue with their proposed probes and access conditions. Missing ratings remain unknown.
- **Review and deliver consistently.** The [standard publication page](../skills/video-production-router/references/preview.md) handles aspect-specific previews, downloads, optional assets and per-field copy. It reuses verified player behavior when the template, server, browser and platform scope match. New files still get their own checks.
- **Carry a series forward.** [RUN//SIGNAL M02 Waterline](productions/run-signal-m02.md) reused M01’s ident, visor and departure with its own route and destination. Outdoor VLC listening passed by owner report; the GPS logger follow-up remains separate. The owner supplied YouTube links for both episodes.
- **Keep decisions tied to actual work.** The package references the [Spotta chart correction](experiments/givemotion-spotta-chart-2026-11-21.md), the [FilmCraft edit/reopen/export trial](experiments/filmcraft-edit-reopen-2026-11-20.md) and new editorial cases on [vineyard financing](productions/french-vineyard-finance.md), [dry ultrasound](productions/dry-ultrasound.md), [ESCAPADE](productions/escapade-powered-flyby.md) and [reaction telemetry](productions/reaction-telemetry.md). Klap and OpusClip remain reference evidence outside the production arsenal.

## Install and upgrade

Download `framewright-router-0.11.0.zip` and compare it with `SHA256SUMS`. Back up the installed router directory, extract the ZIP and replace that directory. Preserve private projects and media separately. Core utilities use standard-library Python. Production renderers, models and provider accounts are optional and remain separate. The release introduces no new project schema.

## Scope

This release records bounded tool and production evidence. It does not establish general model-routing qualification, independent clean-machine operation, labor savings, audience outcomes or automatic publication. Private masters, device routes and training data are outside the package.
